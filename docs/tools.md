# Tool references

* Workflow execution: Di Tommaso et al., Nextflow (2017), doi:10.1038/nbt.3820.
* QC and alignment: [fastp](https://github.com/OpenGene/fastp), [BWA-MEM2](https://github.com/bwa-mem2/bwa-mem2), [SAMtools and BCFtools](https://www.htslib.org/), [mosdepth](https://github.com/brentp/mosdepth), [MultiQC](https://multiqc.info/).
* Small variants: [GATK](https://gatk.broadinstitute.org/), including HaplotypeCaller and Mutect2.
* Copy number and SVs: [CNVkit](https://cnvkit.readthedocs.io/), [Manta](https://github.com/Illumina/manta), [Delly](https://github.com/dellytools/delly), [SURVIVOR](https://github.com/fritzsedlazeck/SURVIVOR).
* RNA: [STAR](https://github.com/alexdobin/STAR), [Arriba](https://github.com/suhrig/arriba), [STAR-Fusion](https://github.com/STAR-Fusion/STAR-Fusion).
* Annotation and benchmarking: [VEP](https://www.ensembl.org/info/docs/tools/vep/), [ANNOVAR](https://annovar.openbioinformatics.org/), [AnnotSV](https://www.lbgi.fr/AnnotSV/), [hap.py](https://github.com/Illumina/hap.py), [Truvari](https://github.com/ACEnglish/truvari).
